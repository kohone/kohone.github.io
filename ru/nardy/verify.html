Проверка костей

Всё считается в вашем браузере, ничего никуда не отправляется. Страницу можно сохранить и открыть без интернета.




Как устроены кости


    

  1. Ключ. Перед партией приложение берёт 32 случайных байта из криптографического генератора телефона. Это секретный ключ партии.
    2. 

  2. Отпечаток. До первого броска приложение показывает SHA-256 ключа — запечатанный конверт. Подобрать другой ключ с тем же отпечатком практически невозможно, поэтому броски нельзя подменить.
    3. 

  3. Бросок номер i (с нуля, включая розыгрыш первого хода) = HMAC-SHA256(ключ, narde-v1|фраза|i). Байты 252–255 пропускаются; каждый остальной байт b даёт кость b mod 6 + 1, поэтому все шесть граней ровно равновероятны. Первые две кости — бросок. Если в блоке меньше двух годных байт (вероятность ≈ 10−55), берётся …|i|1.
    4. 

  4. После партии ключ раскрывается. Его SHA-256 должен совпасть с отпечатком, а броски из него — с журналом бросков в приложении. Уровень компьютера на кости не влияет.

Проверка без нашего сайта


Этой странице можно не доверять. Алгоритм использует только стандартные SHA-256 и HMAC, они есть в любом языке программирования.


Python (на любом компьютере, ничего ставить не нужно):


import hashlib, hmac
key = bytes.fromhex("ВСТАВЬТЕ КЛЮЧ")
phrase = "ВСТАВЬТЕ ФРАЗУ"
print(hashlib.sha256(key).hexdigest())   # должен совпасть с отпечатком
for i in range(60):
    mac = hmac.new(key, f"narde-v1|{phrase}|{i}".encode(), hashlib.sha256).digest()
    print(i, [b % 6 + 1 for b in mac if b < 252][:2])
